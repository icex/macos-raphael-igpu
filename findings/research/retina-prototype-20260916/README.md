# Archived failed Retina-default prototype

Do not install this prototype. On macOS24G830 with candidate280, mode metadata
reported1920×1080 logical/3840×2160 backing, but setting the default later produced
a black desktop. Public-mode rollback failed. The installed LaunchAgent was booted
out and disabled before supervised shutdown and baseline restoration.

These sources preserve the tested implementation and failure for investigation.
They are not a supported setup path. See [the experiment record](../remote-retina-20260916.md).
